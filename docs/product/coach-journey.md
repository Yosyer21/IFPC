# Recorrido del entrenador

1. **Registration**: crear cuenta seleccionando el rol *entrenador*.
2. **Onboarding**: club actual.
3. **Players**: acceder a las fichas de sus jugadores.
4. **Evaluaciones**: valorar aspectos técnicos, físicos, tácticos y psicológicos.
5. **Training**: asignar y supervisar contenidos.

> Las funcionalidades completas de evaluación y asignación de contenidos se desarrollan en próximas fases.
